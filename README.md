# fitch-site

Public pages for the Fitch iOS app, served by GitHub Pages at
https://fatehkhann.github.io/fitch-site/

This repository is generated. Edit the markdown in the Fitch repository under
`ios/Fitch/AppStore/` (English) and `ios/Fitch/AppStore/metadata/<locale>/`
(localized), then regenerate with `python3 build_site.py --out <this folder>`
and push.
